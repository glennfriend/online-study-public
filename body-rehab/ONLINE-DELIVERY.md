# 線上按需載入與舊快取遷移

2026-11-27。本次只改變資料傳送與渲染資源管理，解剖條目、引用、附著背景、運動傷害內容及經覆核的幾何修正保持原樣。

## 首次開啟與互動

主地圖先取得資料及正反面來源投影。四張彩色／物件 ID PNG 合計 1,531,186 bytes，另有 JSON、腳本及 CSS；此數值不是整頁傳輸量或記憶體用量。首次開啟不請求任何獨立 3D 網格。全身位置、正反面切換、逐肌點選及復健／運動參與顏色可直接使用。初始解剖文字照常顯示，局部圖等點選肌肉或「查看這條肌肉的 3D」後才載入。

導覽由同一份來源頂點、三角形及深度測試產生，不重繪肌肉位置。顯示比例超過導覽原生密度前就切回來源 3D；隱藏、深層、單獨定位及骨骼關閉也使用 3D。局部圖保持獨立高解析度渲染。導覽只用於適合其原生解析度的全身視圖。

650 個來源物件分成獨立 gzip，全部合計 54,168,385 bytes。每個檔案含原物件全部頂點及索引，下載時校驗長度與 SHA-256。最多同時下載 6 個檔案，轉換視野會中止舊請求。視野外及被保守遮擋查詢確認不需要的網格會從 GPU 釋放；失敗時顯示重試，不把載入不全的表面當成正確可點選結果。主地圖保留可見鄰近構造的遮擋，附著核對頁只取所選肌肉與既有核對背景。

全身深層等大範圍需求仍可能下載大部分模型；再次回到已釋放的部位可能重新下載。`residentBytes` 只計算目前 GPU 頂點與索引緩衝，不包含導覽紋理、framebuffer、Canvas、JSON、瀏覽器及驅動程式，不能當作完整 RAM 實測。

## 舊版快取清理

`offline-cache.js` 只處理與本資料夾 scope、`sw.js` URL 同時相符的既有註冊。舊 worker 會被原 URL 的退役版本取代，退役版本沒有 fetch handler 或快取寫入；它接管舊頁面、刪除本專案離線資產後自行 unregister。主地圖及附著核對頁等待此步驟完成才開始載入資料，避免舊 worker 又把新網格存入 CacheStorage。沒有既有註冊的新訪客不會安裝 worker。

清理限於 `body-rehab-map-v數字`、`body-rehab-anatomy-v1` 中，URL 位於本資料夾的已知頁面、腳本或資產。相同 cache 中其他專案的 URL 也保留；不使用整個 origin 的 Clear-Site-Data，不清除父站 worker、登入資料、其他快取或使用者資料。清理可重複執行。

其他裝置必須連網造訪更新後的網站才會進行遷移；無法從伺服器立即清掉尚未重訪裝置的本機資料。模型、導覽與主要 JSON 以 `cache: 'no-store'` 請求，不新增離線 CacheStorage、IndexedDB 或 localStorage 模型副本。一般瀏覽器管理的舊 HTTP 快取不在本專案 CacheStorage 清理範圍內，也不以清除整個站台資料的方式處理。

## 驗證

- `node scripts/check-online-delivery.mjs`：逐一解壓全部 650 個物件，與原整包逐 byte 比對頂點及索引；獨立核對每個載入判定盒包住對應三角形；四圖 hash 與來源 hash；混合專案快取保留及重複清理。模擬舊請求在切換後才回應，確認不會將過時網格上傳至 GPU。
- `/scripts/stream-check.html`：實際 WebGL 比對完整模型與按需模型的每個可見物件 ID 像素，涵蓋正反面、深層、單獨定位、骨骼關閉、縮放及平移；確認釋放不用的 GPU 網格。另核對導覽內部像素的來源 ID、所選及動作顏色、下載失敗與重試。
- `/scripts/render-check.html`：原有 16 項 WebGL 渲染、深度遮擋、局部高解析度、足底旋轉及點選回歸檢查。
- 實際頁面：首次開啟 0 個網格請求；點選全身胸大肌可載入局部圖；深層、骨骼背景、單獨定位及放大可用；24 項復健與 9 種運動仍可選取及連動。切到單獨肌肉且關閉骨骼後，目前 GPU 網格降到 1 個。
- `/scripts/cache-check.html` 只讀取並顯示本專案 CacheStorage 與 worker 註冊。實際舊版瀏覽器遷移後，兩者清單皆為空；操作新地圖後仍為空。

這些檢查證明傳輸完整性與互動相容，不取代先前逐條引用的解剖內容核對。原有六項資料／來源檢查也需通過；不重新建置或覆寫文獻審查紀錄。
